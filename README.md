# Voxy — локальный голосовой ввод для macOS

Аналог Spokenly для личного использования: удерживаете **правый ⌘** — идёт запись
(у выреза камеры анимируется «островок»), отпускаете — речь локально распознаётся
моделью **NVIDIA Parakeet TDT 0.6B v3** (мультиязычная, включая русский) и текст
вставляется в позицию курсора активного приложения. Интернет не используется —
всё обрабатывается на устройстве.

## Стек

- **Rust + Tauri v2** — ядро и UI (островок + настройки в неоморфизме)
- **sherpa-onnx** — инференс Parakeet TDT 0.6B v3 int8 (ONNX Runtime, CPU)
- собственный listen-only **CGEventTap** — глобальный хоткей, различает
  левый/правый ⌘ (создаётся строго один раз; см. комментарий в `hotkey.rs` —
  rdev для этого использовать нельзя)
- **cpal** — захват микрофона; **enigo + arboard** — вставка через ⌘V
- **tauri-nspanel** — неактивирующаяся панель островка поверх строки меню

## Запуск (разработка)

```bash
cd src-tauri
cargo tauri dev
```

Сборка приложения: `cargo tauri build` → `src-tauri/target/release/bundle/macos/Voxy.app`.

Модель (~670 МБ) скачивается автоматически при первом запуске в
`~/Library/Application Support/com.dizraid.voice/models/`.

Сквозной тест любой модели каталога без UI (скачивание тем же кодом,
что в приложении — докачка, SHA-256, распаковка — плюс распознавание WAV):

```bash
cargo run --release --example model_smoke -- <model-id> путь/к/файлу.wav <папка-моделей>
```

Юнит-тесты: `cargo test --lib`; сетевой тест провайдеров с ложным ключом:
`cargo test --lib -- --ignored fake_keys`.

Каталог встроен в приложение (`src-tauri/src/catalog.json`): закреплённые
ревизии файлов с SHA-256, метки, языки, оценка памяти и скорости.

| Модель | Метка | На диске | Языки |
|---|---|---|---|
| Parakeet TDT 0.6B v3 | Best balance (по умолчанию) | 670 МБ | 25 европейских |
| Whisper large-v3 turbo | Most languages · Slower | 1.04 ГБ | 99 |
| Qwen3-ASR 0.6B | Asian languages | 987 МБ | 30 |
| Parakeet TDT 110M | Fastest | 136 МБ | английский |
| Moonshine v2 Tiny | Smallest | 44 МБ | английский |

Онлайн-провайдеры с ключом пользователя (ключи — в Связке ключей):

Новые модели раз в сутки ищутся в релизе sherpa-onnx (`discovery.rs`) и
показываются как «Not rated yet»; в каталог они попадают с обновлением
приложения после проверки.

## Разрешения macOS (обязательно)

System Settings → **Privacy & Security**:

1. **Accessibility (Универсальный доступ)** — добавьте Voxy.app (при dev-запуске —
   ваш терминал). Нужно и для глобальной горячей клавиши, и для синтетического ⌘V.
   Без него всё «молча» не работает. Перезапуск не обязателен: приложение само
   подхватит разрешение в течение пары секунд после выдачи.
2. **Microphone** — macOS сам спросит при первой записи.
3. Если хоткей не срабатывает после п.1 — добавьте приложение ещё и в
   **Input Monitoring (Мониторинг ввода)**.

Логи пишутся в `~/Library/Logs/Voxy.log` (переменная `VOICE_LOG_STDERR=1`
переключает вывод в stderr). Приложение одноэкземплярное: повторный запуск
просто открывает окно настроек уже работающей копии.

Диагностика: если в настройках модель «готова», но текст не вставляется —
проверьте Accessibility; распознанный текст в этом случае остаётся в буфере
обмена и в истории (вкладка «История»).

## Настройки

- Горячая клавиша (по умолчанию правый ⌘; захват любой другой по кнопке «Изменить»)
- Режим: Hold (push-to-talk) / Toggle / Dynamic (тап — запись до повторного
  нажатия, удержание ≥1 c — как push-to-talk; отмена кликом по островку)
- Минимальная длительность записи (фильтр случайных нажатий)
- Выбор микрофона, звуки, автозапуск при входе
- История последних 50 диктовок с копированием

## Порт на Windows (задел)

Платформенные части изолированы: `src-tauri/src/platform.rs` (звуки, разрешения,
клавиши вставки — Ctrl+V), ветка `#[cfg(not(target_os = "macos"))]` в `island.rs`
(обычное always-on-top окно вместо NSPanel), хоткей по умолчанию — правый Ctrl
(`store.rs::default_hotkey`). Все зависимости кроссплатформенные.
